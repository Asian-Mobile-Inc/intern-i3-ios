# Tổng hợp project thực hành drawing

## Các kiến thức đã được áp dụng
* Sử dụng override hàm draw kết hợp với UIBerzierPath() để vẽ các hình cơ bản
* Kết hợp các hàm tính toán và các hàm hỗ trợ trong drawing stroke, fill, clip để tạo các hình phức tạp hơn như progress bar, circle chart

## Các vấn đề gặp phải
* Nắm bắt cơ bản nhưng chưa hiểu kĩ được bản chất của CGContext và và push context vào stack, nên lấy ra khi nào và thực sự để làm gì
* Việc dùng draw bằng code để vẽ các hình phức tạp rất khó để hình dùng và không biết code có chạy đụng không nên cần build và sửa nhiều lần 
* => Cần tìm hiểu thêm xem có cách nào draw trên file xib để có thể vẽ một cách trực quan hơn không
